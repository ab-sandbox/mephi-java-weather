## MEPhI Java Weather

Консольное Java-приложение для получения и анализа прогноза погоды с
использованием [API Яндекс Погоды](https://yandex.ru/dev/weather/).

Учебный проект по дисциплине Java (магистратура НИЯУ МИФИ).

### Возможности

- Получение прогноза погоды по географическим координатам.
- Вывод полного JSON-ответа API без изменений.
- Вывод текущей температуры.
- Расчет средней дневной температуры за указанное количество дней.
- Проверка входных параметров и обработка ошибок API.

### Технологии

- Java 21
- Maven
- Java HTTP Client
- Jackson
- SLF4J и Logback
- JUnit 5

### Требования

- JDK 21
- Maven
- API-ключ Яндекс Погоды с доступом к методу `/v2/forecast`

### Сборка

```bash
mvn clean verify
```

Команда собирает проект и запускает автоматические тесты. Для тестов API-ключ и подключение к интернету не требуются.

### Запуск

Перед запуском необходимо задать API-ключ в переменной окружения:

```bash
export YANDEX_WEATHER_KEY="your-api-key"
```

Запуск с параметрами:

```bash
mvn compile exec:java -Dexec.args="55.75 37.62 3"
```

Параметры:

| Параметр    | Описание                                            |
|-------------|-----------------------------------------------------|
| `latitude`  | Широта, от -90 до 90                                |
| `longitude` | Долгота, от -180 до 180                             |
| `limit`     | Количество дней прогноза, положительное целое число |

Запуск без аргументов:

```bash
mvn compile exec:java
```

По умолчанию используются координаты Москвы (`55.75`, `37.62`) и прогноз на 3 дня.

### Результат работы

Приложение выводит:

1. Полный JSON-ответ Яндекс Погоды.
2. Текущую температуру из поля `fact.temp`.
3. Среднюю дневную температуру, рассчитанную по полям `forecasts[*].parts.day.temp_avg` за выбранное количество дней.

Средняя температура рассчитывается как арифметическое среднее значений за дни прогноза.

### Тестирование

Автоматические тесты проверяют:

- Корректность обработки JSON и расчета средней температуры.
- Валидацию координат и количества дней.
- Формирование HTTP-запроса и передачу API-ключа.
- Обработку ошибочных HTTP-ответов.
- Обработку некорректных и неполных данных.

HTTP-клиент тестируется с помощью локального HTTP-сервера, без обращения к реальному API Яндекс Погоды.

### Примечание

API-ключ передается через переменную окружения `YANDEX_WEATHER_KEY` и не хранится в исходном коде или репозитории.
